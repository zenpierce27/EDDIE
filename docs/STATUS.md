# Status and roadmap

Updated: October 20, 2026

Eddie is in preparation for a first source release. This public repository contains documentation only; it does not yet offer application source, a package or a supported version. Development and release-readiness review are underway, with product, content and rights decisions still open. There is no announced launch date.

## Roadmap

1. **Resolve rights and contribution terms.** Confirm ownership, select code and curriculum licenses, and review third-party notices and asset permissions before publishing source or accepting code and content contributions.
2. **Finish product and curriculum review.** Reconcile account-deletion behavior with the intended grace period, prepare lessons in a maintainable text format, and review original learning material.
3. **Verify a releasable source package.** Review the exact export for secrets, private data and asset boundaries; verify dependencies, installation instructions and core reporting flows in a clean environment.
4. **Prepare maintenance and participation.** Define maintainer coverage, contribution instructions and a confidential security-reporting route, then publish documentation that distinguishes working features from planned ones.

These are preparation priorities, not delivery commitments. A hosted service and one-click outlet creation are not offered here.

## How to help now

Use [public issues](https://github.com/zenpierce27/EDDIE/issues) for non-sensitive questions, documentation corrections or suggestions about the learning and reporting workflow. Describe the need and expected outcome; use fictional examples where possible.

Keep private stories, personal information, credentials and non-public security details out of public issues. Code, curriculum and asset contributions should wait until their terms are published. Licensing remains pending; these documents do not grant a license.
