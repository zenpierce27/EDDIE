# Project Eddie

Learn to tell your community’s stories by doing real ones.

Eddie is a storytelling and newsroom project for people learning to report on their communities. It is being developed around short lessons, private story pitches and an editor handoff, so learning happens through real reporting.

**Status: preparation.** This repository currently contains project documentation only. Application source, installation instructions and a supported release are not available here yet. Code and curriculum licensing, ownership review and contribution terms are pending.

See [status and roadmap](docs/STATUS.md) for the remaining preparation work. The roadmap describes priorities, not a release schedule.

## Contributing

Questions about the project, documentation corrections and suggestions are welcome in [public issues](https://github.com/zenpierce27/EDDIE/issues). Please keep examples fictional or non-sensitive: do not post private newsroom material, personal information or credentials.

Please wait to submit code, curriculum or other assets until contribution terms and licensing are published. No license grant is made by these preparation documents. Hosted signup and one-click outlet creation are not available through this repository.
